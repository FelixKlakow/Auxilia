# Auxilia.AI

The [Auxilia](https://github.com/FelixKlakow/Auxilia) AI session abstraction workflows
build agentic steps on: provider-agnostic sessions, typed tool-call capability sinks
(`ICapabilityMcpTools` — structured results come from tool calls, never from "respond with
JSON" prompts), and the MCP plumbing behind them. Referenced by the workflow SDK
(`Auxilia.Workflows`).
